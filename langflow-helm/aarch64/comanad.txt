================================================================================
  Langflow Helm 배포 가이드 (OKE / OCI 환경)
================================================================================

[ 환경 정보 ]
  - 클러스터: OKE (Oracle Kubernetes Engine) / aarch64
  - Ingress Controller: Nginx Ingress Controller
  - 스토리지: OCI FSS (File Storage Service)
  - 데이터베이스: PostgreSQL (postgres 네임스페이스)
  - 배포 방식: ArgoCD (자동 Sync)
  - 접속 도메인: langflow.64bit.kr

================================================================================
1. Helm 차트 정보
================================================================================

  차트: langflow-ide (v0.1.1)
  Repo: https://langflow-ai.github.io/langflow-helm-charts
  Values: langflow-helm/aarch64/values.yaml
  Git: https://github.com/bahn1075/langflow-oracle-component.git (AI/oci 브랜치)

================================================================================
2. ArgoCD Application 배포
================================================================================

  ArgoCD가 Helm 차트 + Git values 파일을 multi-source로 참조하여 자동 배포한다.
  Application 매니페스트는 /app/kubernetes 레포에서 관리된다.

  주요 설정:
    - namespace: langflow (자동 생성)
    - syncPolicy: automated (prune + selfHeal)
    - syncOptions: CreateNamespace=true, ServerSideApply=true
    - ignoreDifferences: StatefulSet volumeClaimTemplates
      (Kubernetes가 VCT에 기본값을 추가하여 ArgoCD diff가 발생하므로 무시 설정)

================================================================================
3. 이미지
================================================================================

  CRI-O 환경에서는 이미지 이름에 반드시 docker.io/ prefix를 붙여야 한다.
  (short name mode enforcing 에러 방지)

  Backend:  docker.io/bahn1075/langflow-custom:aarch64-YYYYMMDD
  Frontend: docker.io/langflowai/langflow-frontend:latest

================================================================================
4. 데이터베이스 (PostgreSQL)
================================================================================

  postgres 네임스페이스에 PostgreSQL이 기동 중이며, langflow DB로 사용한다.

  접속 정보:
    - Host: postgresql.postgres.svc.cluster.local
    - Port: 5432
    - User: postgres
    - Password: postgres123
    - Database: postgres

  values.yaml의 externalDatabase 섹션에서 설정한다.
  sqlite.enabled는 반드시 false로 유지한다.
  (true로 설정하면 StatefulSet에 volumeClaimTemplate이 생성되어
   OCI Mount Target 한도 초과 에러 발생)

  DB 테이블 확인:
    kubectl exec -n postgres <pod-name> -- psql -U postgres -d postgres -c "\dt"

================================================================================
5. 스토리지 (OCI FSS)
================================================================================

  기존 PV/PVC (langflow-fss-pv / langflow-fss-pvc)를 사용한다.
  FSS 마운트 경로 (fss-debug-pod 기준 /mnt):

    /mnt/langflow/flows  -> /app/flows  (flow 파일)
    /mnt/langflow/data   -> /app/data   (데이터)
    /mnt/langflow/db     -> /app/db     (alembic 로그)

  values.yaml의 volumes/volumeMounts에서 subPath로 매핑한다.

================================================================================
6. Ingress
================================================================================

  Nginx Ingress Controller를 사용한다.
  values.yaml에서 설정:
    - kubernetes.io/ingress.class: nginx
    - proxy-body-size: 100m
    - proxy-connect/read/send-timeout: 300s
    - host: langflow.64bit.kr
    - path: / (Prefix)

  접속: http://langflow.64bit.kr
  (Nginx Ingress Controller의 External IP로 DNS가 연결되어 있어야 함)

  주의: 같은 host+path로 중복 Ingress가 있으면 admission webhook이 거부한다.

================================================================================
7. 수동 Helm 설치/업그레이드 (ArgoCD 없이 직접 할 경우)
================================================================================

  helm repo add langflow https://langflow-ai.github.io/langflow-helm-charts
  helm repo update

  helm upgrade --install langflow langflow/langflow-ide \
    --namespace langflow \
    --create-namespace \
    -f langflow-helm/aarch64/values.yaml

================================================================================
8. 트러블슈팅 참고
================================================================================

  [ StatefulSet 업데이트 실패 ]
  StatefulSet의 불변 필드(serviceName, volumeClaimTemplates 등) 변경 시:
    kubectl delete statefulset langflow-service -n langflow --cascade=orphan
  이후 ArgoCD가 새 spec으로 재생성한다. Pod는 orphan으로 유지된다.

  [ ImageInspectError ]
  CRI-O 환경에서 docker.io/ prefix 누락 시 발생.
  values.yaml의 image.repository에 docker.io/를 반드시 포함한다.

  [ Ingress ADDRESS 미할당 ]
  ingressClassName 또는 kubernetes.io/ingress.class annotation이 없으면
  Nginx Ingress Controller가 인식하지 못한다.

  [ PVC Pending (Mount Target 한도 초과) ]
  OCI FSS의 mount-target-count 한도 초과 시 발생.
  sqlite.enabled: false로 설정하여 불필요한 VCT 생성을 방지한다.
